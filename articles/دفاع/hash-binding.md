# اتصال هش (Hash Binding)

> [!tip] خلاصه
> علت ریشه‌ای اکثر حملات (جعل، جایگزینی کلید، کلید شرور) **اتصال هش ناکافی** است: هش امضا شامل تمام اجزایی که باید گره بخورند نیست. راه دفاع: گنجاندن کلیدهای عمومی، مقدار اصلی و تصادفی‌ها در دامنه‌ی هش.

## اصول

1. **گره‌زدن کلید عمومی به مقدار اصلی:** هش باید هر دو بخش `PK` را در بر بگیرد —
   `h = H(ID, X, R, P_pub, m, ...)` ([[wei2025]], p.8, §5).
2. **گره‌زدن تصادفی‌بودن:** هر امضا باید تصادفی تازه داشته باشد؛ استفاده مجدد `{A, PID, T}` شکست می‌خورد ([[shim2023]], p.7, §IV).
3. **پرهیز از معادلات خطی:** ترکیب‌های خطی امکان حذف عبارت `h_3·P_pub` را می‌دهند. راه‌حل: هش‌های `h_5, h_6` وابسته به کلید و تصادفی ([[shim2026]], p.4, §3.3).
4. **پنهان‌کردن ساختار جبری:** به‌جای استفاده مستقیم `Q`، از `H_4(Q)` استفاده شود ([[shim2023]], p.7, §IV).

## فرمول‌های مستند

### اصلاح Zhu-Guan ([[shim2026]])

$$z = h_5 \cdot b + h_6 \cdot c + x \cdot h_4$$
$$zP = h_5 B + h_6 A + h_3 P_{pub} + h_4 X$$
$$h_5 = H_5(PID, X, A, B),\quad h_6 = H_6(PID, X, A, B)$$

### اصلاح Chen-Guan ([[shim2026]])

$$c = h_5 \cdot b + h_6 \cdot vsk + x \cdot h_4$$
$$cP = h_5 B + h_6(U + h_3 P_{pub}) + h_4 X$$
$$h_5 = H_5(PID, P_{pub}, vpk, B, X, m, t),\quad h_6 = H_6(PID, P_{pub}, vpk, B, X, m, t)$$

### اتصال کامل کلید ([[wei2025]])

$$H_1(ID, X_{ID}, R_{ID}, P_{pub})$$

## هزینه

- ~۳n + ۲ ضرب اسکالر در تأیید تجمعی برای n امضا ([[shim2026]], p.4, §3.3).
- گره‌زدن تمام کلیدهای عمومی و تصادفی‌ها به تأخیر غیرقابل چشم‌پوشی منجر می‌شود و مقیاس‌پذیری را در استقرار محدود می‌کند ([[shim2026]], p.4–5, §4).
