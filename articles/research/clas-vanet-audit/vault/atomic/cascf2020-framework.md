# CASCF Framework Algorithms

- Scheme parties are KGC plus sender us and receiver ur with us, ur in an aggregating set a of n users plus an Aggregate Signcryption Generator ASG (p.94750, §II-D)
- Scheme assumes KGC is secure and trusted with aggregation done by ASG and aggregate unsigncryption done by the receiver (p.94750-94751, §II-D)
- Scheme modules run as Setup, Partial private key extract, User key generate, Signcrypt, Aggregate, Aggregate verify and Aggregate unsigncrypt (p.94750, §II-D)
- Preliminaries define cyclic groups G1 additive and G2 multiplicative of order q with a bilinear map e: G1 x G2 -> Ge such that e(u^a, v^b) = e(u, v)^ab (p.94749, §II-B)
$$
\begin{aligned}
&G1 \text{ additive}, G2 \text{ multiplicative}, |G1|=|G2|=q \\
&e: G1 \times G2 \to Ge \\
&e(u^a, v^b) = e(u,v)^{ab}
\end{aligned}
$$
- Setup takes an elliptic curve over Zq, builds additive G1 with generator g1 and multiplicative G2 with generator g2, and sets e: G1 x G1 -> G2 with master secret r and mpk = r.g1.g2 (p.94751, §II-D)
$$
\begin{aligned}
&msk = r \in Z_q^* \\
&mpk = r.g1.g2 \\
&H_1:\{0,1\}^* \to G1, H_2:\{0,1\}^* \to \{0,1\}^k \\
&param = \{G1, G2, e, g1, g2, mpk, H_1, H_2\}
\end{aligned}
$$
- Partial-key extract takes param, msk and IDui with a 128-bit timestamp t, forms Qi = H1(IDui), and returns Pr_d_ui = H1[(msk.Qi)||(t + dt)] over a secure channel (p.94751, §II-D)
$$
\begin{aligned}
&Q_i = H_1(ID_{ui}) \\
&Pr^d_{ui} = H_1[(msk.Q_i)||(t+\delta t)]
\end{aligned}
$$
- User identities are 128-bit ICMetrics values IDui = {0,1}^128 generated by each user for timestamped freshness and revocation checks (p.94751, §II-D)
- User key generation draws ru in Zq*, sets Prui = Pr_d_ui.ru, and publishes Puui = ru.g1.g2 without certification (p.94751, §II-D)
$$
\begin{aligned}
&r_u \in Z_q^* \\
&Pru_{ui} = Pr^d_{ui}.r_u \\
&Puu_{ui} = r_u.g1.g2
\end{aligned}
$$
- Signcrypt draws ri, builds Ui = r2.g1.g2 and Qur = H1(IDur||t), masks M as Vi = hi xor M with Ti = e(mpk, Qur)^r2 and hi = H2(Ui, Ti, ri, Puur, Delta), and signs Wi = ri.Hi + ru.H_Delta (p.94751, §II-D)
$$
\begin{aligned}
&U_i = r_2.g1.g2 \\
&T_i = e(mpk, Q_{ur})^{r_2} \\
&h_i = H_2(U_i, T_i, r_i, Puu_{ur}, \Delta) \\
&V_i = h_i \oplus M \\
&H_i = H_1(U_i, V_i, ID_{ui}, Puu_{ui}, ID_{ur}, Puu_{ur}) \\
&H_\Delta = H_1(\Delta) \\
&W_i = r_i H_i + r_u H_\Delta \\
&C = \{U_i, V_i, W_i\}
\end{aligned}
$$
- Aggregation sums W = sum Wi over n users and packs C = {U1..Un, V1..Vn, W} for transmission by ASG (p.94751-94752, §II-D)
$$
\begin{aligned}
&W = \sum_{i=1}^{n} W_i \\
&C = \{U_1..U_n, V_1..V_n, W\}
\end{aligned}
$$
- Aggregate verification recomputes Hi and H_Delta0 = H1(Delta), forms I1 = e(W, Puui) and I2 = e(sum Qi, mpk) sum e(Hi, Ui) e(H_Delta0, sum Puui), and accepts C only if I1 = I2 (p.94752, §II-D)
$$
\begin{aligned}
&I_1 = e(W, Puu_{ui}) \\
&I_2 = e(\sum Q_i, mpk)\sum e(H_i, U_i)e(H_{\Delta 0}, \sum Puu_{ui}) \\
&\text{accept iff } I_1 = I_2
\end{aligned}
$$
- Aggregate unsigncryption recomputes Ti = e(Ui, Pr_d_ur) and hi = H2(Ui, Ti, rur.Ui, IDur, Prur, Delta), then recovers Mi = Vi xor hi for i = 1..n (p.94752, §II-D)
$$
\begin{aligned}
&T_i = e(U_i, Pr^d_{ur}) \\
&h_i = H_2(U_i, T_i, r_{ur}U_i, ID_{ur}, Pru_{ur}, \Delta) \\
&M_i = V_i \oplus h_i
\end{aligned}
$$
- Conclusion restates that a bilinear map is used in the scheme with timestamped key generation for key freshness (p.94754-94755, §IV)
