# ES-CLAS: An Efficient Certificateless Fully Aggregate Signature Scheme for VANETs

## Overview

This paper proposes ES-CLAS, a certificateless fully aggregate signature scheme for VANETs that addresses the inability of previous schemes to resist forgery attacks and their insufficiently low computation/communication costs. The key innovation is using general one-way hash functions instead of expensive map-to-point hash functions, while achieving full aggregation where signatures from different vehicles on different messages are combined into a single signature.

A lightweight conditional traceability method enables the traffic management department to reveal real identities of malicious vehicles. Security is proven under the ECDL problem, demonstrating existential unforgeability under adaptive chosen-message attacks.

## Relevance to Our Work

ES-CLAS represents the current state-of-the-art in CLAS efficiency for VANETs (2026, IEEE TITS). Its ≥24.3% computation cost reduction is the benchmark our scheme must beat. Its fully aggregate approach and lightweight traceability are key comparison points.

## Key Contributions

- Fully aggregate signature: signatures from different vehicles on different messages combined into one
- General hash functions instead of map-to-point operations — significant efficiency gain
- Lightweight conditional traceability mechanism
- ≥24.3% computation cost reduction vs. compared schemes

## Mathematical Notation

**Key generation:**
- KGC master key $s$, public $P_{pub} = sP$
- User partial key: $D_i = s \cdot H(ID_i)$
- Secret value $x_i$, public key $PK_i = x_iP$

**Signing:**
- Pick random $k_i \in \mathbb{Z}_q^*$
- $R_i = k_iP$
- $c_i = H(ID_i \| m_i \| R_i \| T_i)$ where $T_i$ is timestamp
- $S_i = k_i + c_i \cdot x_i + D_i \mod q$

**Full aggregation:**
$$\sigma = \sum_{i=1}^n S_i, \quad R = \sum_{i=1}^n R_i, \quad C = \bigoplus_{i=1}^n c_i$$

**Verification:**
$$e(\sigma P, P) \stackrel{?}{=} e(R, P) \cdot \prod_{i=1}^n e(c_i PK_i + D_i, P_{pub})$$

## Protocol / Scheme

1. **Setup**: System parameters and master key generation
2. **Extract**: KGC issues partial private key via secure channel
3. **SetKey**: Vehicle generates secret value and public key
4. **Sign**: Vehicle signs message with timestamp, producing $(S_i, R_i)$
5. **Aggregate**: Aggregator computes full aggregate $\sigma$
6. **Verify**: Single verification equation checks all signatures simultaneously
7. **Trace**: TA reveals real identity from pseudonym when malicious behavior detected

## Security Analysis

- Existential unforgeability under adaptive chosen message attack (EUF-CMA)
- Conditional privacy preservation via pseudonym mechanism
- Lightweight traceability: TA can de-anonymize malicious vehicles
- Security proven under ECDL hardness in ROM

## Performance

- Computation: At least 24.3% lower than comparable schemes
- Uses general hash operations (cheaper than map-to-point)
- Full aggregation: single verification for all $n$ signatures
- Communication: Reduced aggregate signature size

## Strengths & Limitations

- Strengths: State-of-the-art efficiency, full aggregation, practical traceability, IEEE TITS publication
- Limitations: ROM-based proof (not standard model), does not explicitly address Type-III adversaries
