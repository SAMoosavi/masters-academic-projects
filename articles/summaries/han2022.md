# eCLAS: An Efficient Pairing-Free Certificateless Aggregate Signature for Secure VANET Communication

> Source mode: Abstract-only. No PDF was available; all claims below come from the IEEE Xplore landing page (title, bibliographic data, and abstract). No scheme equations, parameters, or proofs are reproduced because the full text was not accessible.

## Overview

This paper proposes an efficient pairing-free certificateless aggregate signature scheme named eCLAS, suitable for vehicle-to-infrastructure (V2I) communication in VANETs. The motivation is that signed messages need to be authenticated by roadside units (RSUs) in a very short time under limited network bandwidth and computing power, for which CLAS is considered a promising solution.

## Relevance to Our Work

eCLAS is a V2I-focused pairing-free CLAS efficiency reference: its reported signature-verification advantage over existing schemes makes it a relevant comparison point for verification-cost targets.

## Key Contributions

- Proposes pairing-free CLAS scheme eCLAS for V2I communication in VANETs
- Aggregates individual signatures on different messages from different vehicles into one short signature
- Proves security in the random oracle model under adaptive chosen-message attack and the elliptic-curve discrete logarithm assumption
- Reports obvious advantages in signature verification over existing schemes with better applicability
