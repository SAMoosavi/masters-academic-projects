# eCLAS: An Efficient Pairing-Free Certificateless Aggregate Signature for Secure VANET Communication

## Overview

eCLAS proposes an efficient pairing-free CLAS scheme for vehicle-to-infrastructure (V2I) communication in VANETs. The aggregated signature allows individual signatures on different messages from different vehicles to be combined into one short signature, significantly reducing verification overhead for roadside units.

Security is proven in ROM against adaptive chosen message attacks under the discrete logarithm problem on elliptic curves. The scheme demonstrates obvious advantages in signature verification time compared to existing approaches, making it highly applicable to real-time VANET authentication scenarios.

## Relevance to Our Work

eCLAS is a key efficiency benchmark for pairing-free CLAS in VANETs. Its V2I focus and verification advantages are directly comparable to our scheme's performance targets.

## Key Contributions

- Pairing-free CLAS optimized for V2I communication
- Significant verification time advantages over existing schemes
- Proven secure under discrete logarithm assumption
- Practical for real-time VANET authentication

## Mathematical Notation

**Key generation:**
- KGC: master key $s$, public $P_{pub} = sP$
- Partial key: $D_i = sH(ID_i)$
- Secret value $x_i$, public key $PK_i = x_iP$

**Signing:**
- Random $r_i \in \mathbb{Z}_q^*$
- $R_i = r_iP$
- $h_i = H(m_i \| ID_i \| R_i \| PK_i)$
- $\sigma_i = r_i + h_i \cdot x_i + D_i \mod q$

**Aggregation:**
$$\sigma = \sum_{i=1}^n \sigma_i, \quad R = \sum_{i=1}^n R_i, \quad H = \prod_{i=1}^n h_i$$

**Verification (single pairing-free equation):**
$$e(\sigma P, P) = e(R, P) \cdot e(H \cdot PK_i + H_1(ID_i), P_{pub})$$

## Protocol / Scheme

1. **Setup**: Parameter and master key generation
2. **Extract**: Partial private key issuance
3. **SetKey**: Vehicle public key generation
4. **Sign**: Message signing with timestamp
5. **Aggregate**: RSU collects and aggregates signatures
6. **Verify**: Single pairing verification checks all signatures

## Security Analysis

- EUF-CMA in ROM under DL assumption
- Conditional privacy via pseudonyms
- Resists Type-I and Type-II adversaries

## Performance

- Pairing-free: eliminates most expensive operation
- Verification: constant-time regardless of $n$ signatures
- Advantages in signature verification vs. comparable schemes

## Strengths & Limitations

- Strengths: Practical V2I focus, strong efficiency gains, IEEE Systems Journal
- Limitations: Does not address Type-III adversaries, ROM-based proof
