# A New Efficient and Provably Secure CLS Without Bilinear Pairings for IoT

## Overview

This paper demonstrates that many pairing-free certificateless signature (PF-CLS) schemes share the same security vulnerability to forged signature attacks. Using a novel attack method, the authors prove that a class of PF-CLS schemes cannot resist Type I adversary attacks. Even when schemes are improved to block existing attack methods, they remain vulnerable to the new attack proposed.

The authors then introduce an enhanced scheme proven resilient against both Type I and Type II adversary attacks in ROM. Performance analysis shows higher computational efficiency than existing PF-CLS schemes.

## Relevance to Our Work

While focused on CLS (not CLAS) and IoT (not VANETs), this paper's attack methodology is relevant — it shows that many "secure" pairing-free schemes share a common vulnerability class. Our CLAS scheme must be analyzed against this class of attacks.

## Key Contributions

- Novel attack method against a class of PF-CLS schemes
- Proves existing schemes cannot resist Type I adversary attacks
- Enhanced scheme resisting both Type I and Type II adversaries
- Higher computational efficiency than comparable schemes

## Mathematical Notation

**Attack on existing PF-CLS:**
- Adversary uses forged signature with manipulated random values
- Type I attack: adversary replaces public key and exploits verification equation structure

**Enhanced scheme:**
- KGC: $s$, $P_{pub} = sP$
- Partial key: $D_i = sH(ID_i)$
- Secret value $x_i$, $PK_i = x_iP$
- Sign: Modified algorithm resisting Type I attacks
- Verification: Pairing-free equation

## Protocol / Scheme

2. **Enhanced signing**: Modified signature algorithm
3. **Verification**: Updated verification equation
